Разбор по экранам

Каждый экран решает конкретную задачу

Никакой воды — только функциональные блоки, которые работают на продажи и автоматизацию.

01

Первый экран: 3 секунды на решение

Тёплые тона, живые фото, минимум текста — максимум ощущения. Два чётких CTA: «Выбрать тариф» и «Узнать больше». Sticky-хедер с кнопкой действия остаётся на экране при прокрутке — клиент может купить с любой точки страницы.

Hero-секцияSticky-хедерДвойной CTA
Почему это работает: пользователь принимает решение о доверии в первые 3 секунды. Правильный визуал и понятное действие резко увеличивают время на сайте и конверсию.
02

Раздел «О клубе»: доверие через смыслы

Посетитель чувствует атмосферу клуба ещё до записи. Сторителлинг, фото из жизни, ценности — всё это формирует эмоциональную связь, которая конвертирует «интересно» в «хочу вступить».

Фото-коллажСторителлингЦенности клуба
Деталь: анимации при скролле появляются последовательно — сначала текст, потом фото. Это создаёт ощущение «живого» рассказа, а не статичной страницы.

03 — Расписание на неделю

7 дней, цветовые метки по типам активностей, время и название. Больше никаких PDF в чате и вопросов «а что у вас в субботу?». Всё обновляется из Google Таблицы — без программиста.

04

Календарь на месяц: клиент сам управляет

Отдельная страница с полным расписанием. Фильтрация по типам активностей, навигация по месяцам, бейдж «сегодня». Цветовое кодирование — взгляд сразу находит нужное.

Самое важное: данные подтягиваются из Google Таблицы. Обновили строчку — сайт обновился. Без обращений к дизайнеру, без технической сложности для владельца.

Отдельная страницаФильтрыGoogle SheetsАвтообновление
Это — ключевая автоматизация: раньше обновление расписания = ручная работа + новый PDF + публикация в сторис. Теперь = одна строчка в таблице.

05 — Сетка месяца

Работает как мобильное приложение — интерактивная навигация, цветовые метки, мгновенный отклик. Клиент планирует свой месяц прямо на сайте.

06

Галерея + виральный контент

Фото-сетка из жизни клуба показывает реальную атмосферу, которую невозможно передать текстом. Плюс CTA-баннер с переходом на отдельную страницу.

Отдельная страница — чеклист «45+ вещей, которые веселее делать вместе». Это виральный лид-магнит: люди сохраняют и репостят в сторис → органический трафик без бюджета на рекламу.

Фото-сеткаCTA-баннерЛид-магнитВирусный контент
Маркетинговая механика: пользователь делится чеклистом → его подписчики видят упоминание клуба → новые люди приходят органически. Без затрат.
07

Тарифы и оплата: деньги без участия владельца

Два тарифа, понятное сравнение, форма заявки с автоматическим расчётом суммы. Оплата через Prodamus — клиент платит картой прямо на сайте, деньги уходят на счёт владельца автоматически.

Самое ценное: счётчик свободных мест в реальном времени подтягивается из Google Таблицы. Видя «осталось 2 места», клиент принимает решение быстрее.

ТарифыМодальная формаProdamusСчётчик местРеальное время
Эффект срочности: «Осталось 2 места на субботу» — это не манипуляция, а реальные данные из таблицы. Конверсия в моментальную оплату выше, чем без счётчика.
